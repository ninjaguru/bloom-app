# Skill: AtHomeSalonServiceManager

## Metadata
- **Name:** At-Home Salon Service Manager
- **Description:** Manages hyper-local on-demand beauty and grooming services catalog routing, package scaling calculations, and Firestore state sync pipelines.

## Instructions
1. Filter all service queries strictly based on the primary `gender` value (`women` or `men`) passed through the application UI state to optimize regional indexing.
2. Calculate bundle tier discounts dynamically on the client-side state. If a custom package bundle is constructed, apply scaled deductions (up to 20% max) prior to pushing the intent record to the Firestore transaction queue.
3. Serve dynamic imagery and auto-playing operational video banners leveraging optimized formats (`.webp` and highly compressed mp4 streams) delivered over the global edge CDN paths.

## Environment Requirements
- **Runtime Tools:** Flutter Engine, Firebase Core (FlutterFire CLI SDK)
- **Target Extensions:** GeoFirestore geospatial coordinate calculations for matching partners.
